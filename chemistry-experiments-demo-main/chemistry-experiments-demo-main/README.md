# الكيمياء التفاعلية (Interactive Chemistry Lab & Curriculum App)

تطبيق كيمياء تفاعلي متقدم للصف السادس العلمي (المنهج العراقي)، يشتمل على تجارب 2D متطورة للمسعر الحراري، أسئلة وزارية تفاعلية، شروحات متقدمة، ومساعد ذكي.

## 🚀 المميزات الرئيسية (Key Features)

1. **المسعر الحراري 2D التفاعلي (Interactive 2D Calorimeter Lab)**:
   - محاكاة فيزيائية متكاملة لقياس انثالبي الاحتراق (الماء المقطر 1000g، عينة الجلوكوز 3g، قنبلة O₂، أسلاك الاشتعال والمحراك).
   - انميشن سكب الماء وانسياب الموائع.
   - انميشن انتشار الموجات الحرارية (`Radiant Heat Diffusion Waves`).
   - شرارة كهربائية عالية الفولتية ولهب احتراق متوهج متعدد الطبقات.
   - رسم بياني مباشر وتغير درجات الحرارة لحظياً ($T_i \rightarrow T_f$).

2. **محاكاة الاتزان الديناميكي 2D (Dynamic Equilibrium 2D Lab)**:
   - محرك فيزيائي فائق السلاسة بمعدل **60 FPS** يعمل بنظام `requestAnimationFrame`.
   - **حماية رحلة الذهاب**: جزيء **2NH** المتكون لا يتفكك إطلاقاً أثناء رحلة انطلاقه يميناً نحو منطقة النواتج.
   - **تفكك رحلة العودة**: يتفكك **2NH** إلى **1 N زرقاء + 1 H حمراء** حصرياً عند عودته مرتحلاً يساراً من منطقة النواتج.
   - خيارات التحكم بالسرعة التفاعلية (**0.25x الحركة البطئية للغاية**, 0.5x, 1x, 2x, 4x) لرصد التصادمات الدقيقة.
   - سهم التفاعل المزدوج الديناميكي ($N + H \rightleftharpoons 2\text{NH}$) في منتصف الوعاء مع أسهم متجهة لاتجاه سرعة كل جزيئة.
   - حسم حالة الاتزان عند تساوي سرعة التفاعل الأمامي والعكسي مع ثبات التراكيز.

3. **تصميم احترافي خالي من الإيموجيات النصية**:
   - اعتماد مكتبة الأيقونات المتجهية `lucide-react` لجميع الأقسام المقالية والبطاقات التعليمية.

3. **لوحة تحكم وشروحات شاملة**:
   - متابعة تقدم الطالب عبر الفصول الثمانية، واختبارات ذكية مع حاسبة كيميائية.

## 💻 التشغيل المحلي (Run Locally)

1. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير (Run dev server):**
   ```bash
   npm run dev
   ```

3. **فتح التطبيق عبر الرابط المباشر:**
   - [http://localhost:3000](http://localhost:3000)
