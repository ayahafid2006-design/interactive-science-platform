 الأولوية للمحركات المشتركة (Shared Core First)
القاعدة: يُمنع بناء نظام سحب وإفلات، أو كتابة خوارزمية توصيل أسلاك خاصة داخل أي تجربة.
التطبيق: استخدم دائماً المكونات العامة الموحدة:
الإدارة والسحب والتحجيم: EliteEngine
رسم الأسلاك والتوجيه: SVGWireEngine
تصاميم القطع (بطارية، مفتاح، مقياس): EliteComponents
2. الحيادية التامة للمحركات (Domain-Agnostic Core)
القاعدة: يُحظر كتابة أي معرّف خاص (ID)، أو شرط خاص بتجربة معينة، أو معادلة فيزيائية داخل svg-wire-engine.js أو elite-engine.js.
التطبيق: المحركات تتعامل فقط مع مفاهيم مجردة (.component, .drop-zone, .terminal-node, obstacles). الفيزياء تنتمي لملف التجربة (.html) فقط.
3. التوسيع عبر الإعدادات بدون كسر القديم (Extend via Config)
القاعدة: إذا احتاجت تجربة جديدة سلوكاً غير موجود في المحرك العام:
أضف الميزة كخيار تهيئة اختياري (config / options) مع وضع قيمة افتراضية تحافظ على السلوك القديم.
لا تعدل منطق دالة عامة بدون توفير Backward Compatibility 100%.
4. مصفوفة فحص الأمان (Cross-Experiment Smoke Check)
القاعدة: في حال تعديل أي حرف داخل مجلد src/engine/ أو src/css/raqeem-experiment.css، يجب التحقق من عدم انكسار التجارب المعيارية الثلاث:
تجربة المتسعات: src/experiments/parallel.html
تجربة فاراداي: src/experiments/faraday.html
تجربة التيار المتناوب: src/experiments/intro_dc_vs_ac.html
5. المزامنة والتوثيق الحتمي (Sync & Dev Log)
القاعدة:
أي ملف يتم تعديله في src/ يُنسخ فوراً بنفس الأمر إلى dist/src/.
كل قرار أو تعديل يُسجل في agent_dev_log.md ليعرف الـ AI القادم أين توقف العمل ولماذا اتُّخذ هذا القرار.
