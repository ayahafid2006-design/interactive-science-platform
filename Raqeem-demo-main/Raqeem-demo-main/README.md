# مختبرات رقيم — النسخة التجريبية (RAQEEM DEMO)

بوابة تعليمية تفاعلية لمناهج الفيزياء (السادس العلمي) — إصدار تجريبي محدود مخصص للعرض والتقديم.

## 📝 وصف المشروع
مختبرات رقيم هي منصة تعليمية رائدة تهدف إلى تحويل مفاهيم الفيزياء المجردة إلى تجارب بصرية تفاعلية ملموسة. باستخدام أحدث تقنيات الويب، تتيح المنصة للطلاب التفاعل المباشر مع الظواهر الفيزيائية، مما يسهل فهم القوانين والمفاهيم المعقدة. 
تم تصميم هذه النسخة التجريبية خصيصاً لتتوافق مع منهج الفيزياء للصف السادس العلمي، وتتميز بواجهة مستخدم عصرية (UI) وتجربة مستخدم سلسة (UX) تدعم جميع الأجهزة، بما في ذلك الهواتف الذكية.

## 🌟 المحتوى التجريبي المشمول
1. **الفصل الأول — المتسعات**:
   - العوازل غير القطبية (`nonpolar.html`): محاكاة تفاعلية لتأثير العازل غير القطبي وتولد المجال الكهربائي المحتث.
   - لوحة مفاتيح الحاسوب (`capacitor_application_keyboard.html`): تطبيق عملي يوضح كيف تعمل المتسعات في لوحة المفاتيح.
   - ربط المتسعات على التوازي (`parallel.html`): مختبر تفاعلي لبناء دائرة توازي وحساب السعة المكافئة والشحنات.
2. **الفصل الثاني — الحث الكهرومغناطيسي**:
   - حركة الجسيمات المشحونة (`fields_effect.html`): محاكاة لحركة الجسيمات داخل المجالات الكهربائية والمغناطيسية وتأثير قوة لورنتز.
   - تجربة حلقة فراداي (`faraday_experiment.html`): تجربة تفاعلية تاريخية توضح قانون فراداي في الحث الكهرومغناطيسي باستخدام محرك الأسلاك المتعامد ومصنع المكونات الموحد.
3. **الفصل الثالث — التيار المتناوب**:
   - مقارنة المستمر والمتناوب (`intro_dc_vs_ac.html`): مقارنة بصرية بين دوائر التيار المستمر والمتناوب مع راسم إشارة تفاعلي.
   - المقدار المؤثر للتيار (المكافئ الحراري) (`concept_rms_thermal_effect.html`): محاكاة حرارية توضح مفهوم المقدار المؤثر للتيار المتناوب.

## 🛠️ التقنيات المستخدمة
- **HTML5 & CSS3**: لبناء الهيكل وتنسيق الصفحات.
- **Tailwind CSS**: لتصميم واجهات عصرية ومتجاوبة بالكامل مع الأجهزة المحمولة.
- **GSAP (GreenSock)**: لإنشاء حركات وانيميشن فيزيائية دقيقة وسلسة.
- **MathJax**: لعرض المعادلات الفيزيائية والرياضية بشكل احترافي.
- **JavaScript (Vanilla)**: لبرمجة المنطق الفيزيائي، محرك الأسلاك، والتفاعلات.

## 📱 التوافق والتجاوب
تم تحسين جميع التجارب في هذه النسخة للعمل بكفاءة عالية على الأجهزة المحمولة (Mobile Responsiveness). تم استخدام تقنيات العرض المرن لتضمان تكيف الواجهات، بالإضافة إلى تمكين التمرير الأفقي لمساحات العمل التفاعلية لضمان عدم تأثر التصميم الأساسي على الشاشات الصغيرة.
